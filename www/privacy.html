축의대 앱 개인정보처리방침

시행일: 2026년 10월 13일

1. 수집하는 정보

축의대 앱은 사용자가 직접 입력한 접수 내역(이름, 금액, 메모 등)을 사용자의 기기 안에만 저장합니다. 앱은 서버를 운영하지 않으며, 입력한 내용을 인터넷으로 전송하거나 외부에 보관하지 않습니다.

2. 기기 밖으로 나가는 경우

사용자가 "엑셀로 저장" 또는 "백업 파일 저장"을 눌러 직접 파일을 내보내거나 공유할 때에만, 사용자가 고른 앱(메신저, 메일, 파일 앱 등)으로 전달됩니다. 이 과정은 전적으로 사용자의 조작으로만 일어납니다.

3. 광고·분석·제3자 제공

광고, 사용 분석 도구, 제3자 SDK 를 사용하지 않으며 어떠한 정보도 제3자에게 제공하지 않습니다.

4. 보관과 삭제

저장된 내역은 사용자가 앱을 삭제하거나 브라우저의 사이트 데이터를 지우면 함께 삭제됩니다.

① 웹으로 쓰기 (추천 · 누구나)

설치 파일 없이 브라우저에서 바로 쓰고, 홈 화면에 추가하면 앱처럼 아이콘으로 열립니다. 한 번 열어 두면 인터넷이 없어도 동작합니다.

아이폰 · 아이패드

  1. 사파리로 아래 주소를 엽니다. (크롬·네이버·카카오톡 안에서 말고 꼭 사파리)
    https://dlwnsdyd21-del.github.io/chuguidae/
  2. 화면 아래 공유 버튼(네모에 위쪽 화살표)을 누릅니다.
  3. "홈 화면에 추가" → 오른쪽 위 추가
  4. 홈 화면에 생긴 축의대 아이콘으로 엽니다.
  5. 첫 화면에 "✓ 인터넷 없이 사용할 준비가 되었습니다"가 보이면 완료!

⚠ 아이폰은 사파리 화면과 홈 화면 아이콘의 기록이 따로 저장돼요. 예식 만들기와 입력은 꼭 홈 화면 아이콘으로 연 화면에서 하세요.

안드로이드 (웹으로)

  1. 크롬으로 아래 주소를 엽니다.
    https://dlwnsdyd21-del.github.io/chuguidae/
  2. 첫 화면의 "이 기기에 앱으로 설치" 버튼을 누릅니다.
    (버튼이 안 보이면 크롬 오른쪽 위 ⋮ → "홈 화면에 추가" 또는 "앱 설치")
  3. 홈 화면의 축의대 아이콘으로 엽니다.
  4. 첫 화면에 "✓ 인터넷 없이 사용할 준비가 되었습니다"가 보이면 완료!

플레이스토어 앱으로 받고 싶다면 아래 ② 안드로이드 앱을 보세요.

노트북 · PC

  1. 크롬 또는 엣지로 아래 주소를 엽니다.
    https://dlwnsdyd21-del.github.io/chuguidae/
  2. 첫 화면의 "이 기기에 앱으로 설치"를 누르면 바탕화면·시작 메뉴에 아이콘이 생깁니다. (안 눌러도 바로 사용 가능)
  3. 엑셀 파일은 다운로드 폴더에 저장됩니다.

시크릿(InPrivate) 창에서는 기록이 남지 않으니 일반 창으로 쓰세요.

② 안드로이드 앱으로 쓰기 (테스트 참여)

구글 플레이스토어 정식 출시 전 테스트 기간이라, 아래 두 단계를 순서대로 해야 설치할 수 있어요. 기능은 웹 버전과 같습니다.

  1. 테스터 그룹 가입
    테스터 그룹 을 열고 "그룹 가입"을 누릅니다.
  2. 테스트 참여 후 설치
    테스트 참여 링크 를 열고 "테스터 되기" → "Google Play에서 다운로드" → 설치

⚠ 1·2번 모두 플레이스토어에 로그인된 같은 구글 계정으로 해 주세요.
⚠ "앱을 찾을 수 없음"이 나오면 1번(그룹 가입)을 먼저 했는지, 계정이 같은지 확인해 주세요. 가입 직후에는 반영까지 몇 분 걸릴 수 있어요.
🙏 테스트 기간(2주) 동안 앱을 지우지 말아 주세요. 정식 출시에 큰 도움이 됩니다.

이렇게 쓰세요

  1. "+ 새 예식 만들기" → 신랑측/신부측, 이름, 날짜 입력
  2. 봉투를 받으면 이름 → 금액(3만·5만·10만 버튼) → 누구 손님 → 저장
  3. 화면에 나온 접수 번호를 봉투에 적어 두면 나중에 봉투와 하나씩 맞춰 볼 수 있어요.
  4. 이름을 알아보기 어려우면 "이름 확인 어려움"을 체크하고 단서를 메모
  5. 끝나면 더보기 → 접수 마감 → 엑셀로 저장 → 카카오톡 등으로 혼주님께 전달

꼭 알아 두세요

  • 입력한 내용은 내 기기에만 저장되고 어디에도 전송되지 않아요. 회원가입도 없어요.
  • 같은 폰에서 웹 버전과 앱 버전은 기록이 따로 저장돼요. 한 가지만 골라 쓰세요.
  • 브라우저의 "사이트 데이터 삭제"를 하거나 앱을 지우면 기록도 지워져요. 중간중간 더보기 → 백업 파일 저장을 해 두면 안전해요.
  • 예식 전날 미리 설치하고, 비행기 모드에서 열리는지 한 번 확인해 두세요.
  • 여러 기기로 동시에 받으면 기기마다 번호가 따로 매겨지고 엑셀도 기기별로 나와요.

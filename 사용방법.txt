축의대 앱 사용 방법
====================

■ 설치 방법 세 가지 (하나만 고르면 됩니다)

  1) 앱 스토어에서 설치 (플레이스토어 / 앱스토어 등록 뒤)
     "축의대" 를 검색해 설치합니다. 가장 간단합니다.

  2) 안드로이드 APK 파일로 직접 설치 (스토어 등록 전에도 가능)
     GitHub 의 Releases 페이지에서 chuguidae-….apk 를 내려받아 휴대폰에서 누르면 설치됩니다.
     https://github.com/dlwnsdyd21-del/chuguidae/releases
     "출처를 알 수 없는 앱" 경고가 나오면 설정에서 허용을 눌러 주세요.

  3) 설치 없이 웹으로 (휴대폰·태블릿·노트북 모두)
     https://dlwnsdyd21-del.github.io/chuguidae/
     아래 "홈 화면에 추가" 방법을 따르면 앱처럼 쓸 수 있습니다.

  ※ 어떤 방법이든 입력한 축의금 내용은 기기 안에만 저장되고 어디에도 전송되지 않습니다.
  ※ 방법 1·2 로 설치한 앱과 방법 3 의 웹 앱은 기록이 서로 따로 저장됩니다. 한 가지만 쓰세요.


■ 웹 앱을 홈 화면에 추가하기 (방법 3을 고른 경우, 예식 전날까지 미리)

  [안드로이드 - 크롬]
  1. 크롬으로 위 주소를 엽니다.
  2. 첫 화면의 "이 기기에 앱으로 설치" 버튼을 누릅니다.
     (버튼이 안 보이면 크롬 메뉴 ⋮ → "홈 화면에 추가" 또는 "앱 설치")
  3. 홈 화면에 생긴 "축의대" 아이콘으로 엽니다.

  [아이폰·아이패드 - 사파리]
  1. 사파리로 위 주소를 엽니다. (크롬·네이버 앱 말고 반드시 사파리)
  2. 아래쪽 공유 버튼(네모에 위 화살표) → "홈 화면에 추가" → 추가
  3. 인터넷이 켜진 상태에서 홈 화면의 "축의대" 아이콘으로 한 번 엽니다.
     ★ 아이폰은 사파리 화면과 홈 화면 앱의 기록이 따로 저장됩니다.
        예식 만들기와 입력은 반드시 홈 화면 아이콘으로 연 화면에서 하세요.

  [공통 확인]
  · 첫 화면에 "✓ 인터넷 없이 사용할 준비가 되었습니다"가 보이면 완료입니다.
  · 비행기 모드를 켜고 아이콘으로 다시 열어 보세요. 열리면 당일에도 문제없습니다.
  · 카카오톡으로 주소를 받아 누르면 카카오톡 안의 화면으로 열립니다. 거기서는 설치가
    안 되니 메뉴에서 "다른 브라우저로 열기"를 눌러 크롬/사파리에서 여세요.


■ 노트북(윈도우/맥)에서 쓰기
  · 방법 1: 크롬/엣지로 위 주소를 열고 "이 기기에 앱으로 설치"를 누릅니다.
  · 방법 2: 이 폴더의 www/index.html 을 더블클릭해 크롬/엣지로 엽니다. (인터넷 전혀 필요 없음)
  · 항상 같은 브라우저로 열어야 이전 기록이 보입니다. 시크릿 창은 쓰지 마세요.
  · 방법 1과 방법 2의 기록은 서로 따로 저장됩니다. 한 가지만 쓰세요.


■ 당일 순서
  1. "새 예식 만들기" → 신랑측/신부측, 이름, 날짜 입력
  2. 봉투를 받으면: 이름 → 금액(3만/5만/10만 버튼) → 누구 손님(선택) → 저장
     · 이름을 알아보기 어려우면 "이름 확인 어려움"을 체크하고 단서를 메모에 적습니다.
     · 저장하면 접수 번호가 크게 나옵니다. 봉투에 같은 번호를 적어 두면
       나중에 봉투와 기록을 하나씩 맞춰 볼 수 있습니다.
  3. 잘못 입력했으면 "목록"에서 눌러 수정하거나 접수 취소를 합니다.
     (지워지지는 않고, 바뀐 내용은 변경 이력에 남습니다.)
  4. 끝나면 "더보기" → "접수 마감" → "엑셀로 저장" → 혼주께 파일 전달
     · 안드로이드/노트북: 다운로드 폴더에 저장됩니다. 파일 앱이나 카카오톡의
       파일 첨부에서 골라 보내세요.
     · 아이폰/아이패드: 공유 창이 뜹니다. "파일에 저장" 또는 카카오톡·메일을 고르세요.
     · 혹시 모르니 "백업 파일 저장"도 함께 해 두세요.


■ 엑셀 파일 구성
  · 접수 내역   : 전체 목록. 머리글에 필터가 걸려 있고, 위쪽 합계는 수식이라
                  필터를 걸면 보이는 행만 합산됩니다. 취소 건은 합계에서 빠집니다.
  · 구분별 합계 : 누구 손님별 건수·금액·식권 (수식)
  · 변경 이력   : 접수·수정·취소·마감 기록


■ 주의
  · 브라우저의 "인터넷 사용 기록/사이트 데이터 삭제"를 하면 기록도 지워집니다.
  · 아이폰에서 홈 화면 아이콘을 삭제하면 그 안의 기록도 함께 지워집니다.
    지우기 전에 반드시 엑셀과 백업 파일을 저장하세요.
  · 중간중간 "백업 파일 저장"을 해 두면 안전합니다.
  · 여러 기기에서 동시에 받으면 기기마다 번호가 따로 매겨집니다.
    (엑셀 파일도 기기별로 하나씩 나옵니다.)
  · 앱을 고친 뒤 다시 배포하는 방법은 배포안내.md 를 보세요.
    (더보기 맨 아래에 앱 버전이 표시됩니다.)
